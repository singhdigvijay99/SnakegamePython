## 📖 Overview

This project recreates the classic Snake Game, one of the most iconic arcade games ever made.

The objective is simple:

* Control the snake.
* Eat the food to increase your score.
* Grow longer with every meal.
* Avoid hitting the walls or your own body.

This project was built to explore Python game development concepts and event-driven programming.

* 🐍 Smooth snake movement

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/singhdigvijay99/SnakegamePython.git
```

### Navigate to the project

```bash
cd SnakegamePython
```

### Run the game

```bash
python snake.py
```

> Replace `snake.py` with your main Python file if it has a different name.
